# ファンタジーすごろく

ファンタジー世界の土地を買い集める、すごろく型の資産ゲーム（Web版）。

遊ぶ：https://arashi0-git.github.io/fantasy-sugoroku/

## 動かし方

```bash
npm install
npm run dev      # 開発用サーバー（http://localhost:5173）
npm test         # ルールのテスト
npm run build    # 公開用ビルド（dist/）
npm run build:single   # 1つのHTMLにまとめたビルド（dist-single/）
npm run sim      # CPU同士の自動対戦でバランスを確認（src/ai/balance.sim.ts）
```

## フォルダ構成

```
src/
  core/   ルールと状態（画面を知らない純粋な TypeScript）
    game.ts       applyAction(state, action) で次の状態を返す
    rng.ts        シード付き乱数
    game.test.ts  Vitest のテスト
  data/   マス一覧（board.ts）、経済バランスの初期値（config.ts）、手札カード（cards.ts）、キャラクター（characters.ts）、秘密の使命（missions.ts）
  ai/     CPU の性格（personality.ts）と判断（cpu.ts）、一言のセリフ（speech.ts）、CPU同士の自動対戦テスト
  ui/     画面の描画（view.ts）とスタイル（style.css）
  main.ts 画面とルールをつなぎ、サイコロとコマの演出を行う
```

## 公開とセキュリティ

main に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテストとビルドをして GitHub Pages に公開する。

- 使う Action はコミットのハッシュで固定している。更新は Dependabot（`.github/dependabot.yml`）がプルリクエストで知らせる
- ワークフローの権限は最小限。公開のジョブだけが Pages に書き込める。プルリクエストからは動かない
- 依存は `package-lock.json` どおりに入れ、インストール時のスクリプトは実行しない（`npm ci --ignore-scripts`）
- 公開用のページには Content-Security-Policy を入れている。読み込めるのは自分のスクリプト・スタイルと Google Fonts だけで、外への通信・フォーム送信・埋め込みは禁止
- ゲームはブラウザの中だけで動き、サーバーへの送信や個人情報の保存はしない
